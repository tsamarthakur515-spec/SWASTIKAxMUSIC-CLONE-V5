# 🎵 Swastika Music V5

**High quality, fast Telegram music bot** by **Samar**.

Swastika Music V5 is a full-featured Telegram music bot built for smooth audio & video streaming in voice chats. It comes with moderation tools, chatbot, games, locks, welcome system, and more — all in one package.

---

## ✨ Features

- **Music** — Play / VPlay / Pause / Resume / Skip / End in voice chat
- **Tools** — Stats, active chats, welcome messages, broadcast
- **Moderation** — Mute, ban, kick, tagall, noabuse filter
- **Chatbot** — AI chat powered by Groq API
- **Locks** — Lock content types (url, photo, video, media, etc.)
- **Games** — Economy, RPG, social friends, slots, dice, riddle, coinflip
- **Premium UI** — Custom emoji buttons & styled menus

---

## 🚀 Setup

1. Fill `Config.env` (bot token, API IDs, Groq key, etc.)
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the bot:
   ```bash
   python3 main.py
   ```

**Default Groq model:** `openai/gpt-oss-20b`
